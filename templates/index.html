        Capabilities

          Local data

          Conversation history, settings and theme preference are stored in this browser's localStorage. Nothing is sent to a third party by the interface itself.

          Credentials

          Model and research API keys live in the server environment file and are never exposed to the browser. The interface only reads boolean capability flags.
